# Third-party visual assets

The 24 static ASL reference photos in `assets/signs/` were cropped from
`amer_sign2.png`, distributed inside the **Sign Language MNIST** dataset by
Datamunge on Kaggle:

https://www.kaggle.com/datasets/datamunge/sign-language-mnist

The Kaggle dataset page identifies the dataset license as **CC0: Public
Domain**. The photos are included only as introductory visual references for
the supported static alphabet classes. J and Z require motion and are not
represented by this image dataset or the 24-class classifier.
